# Mission map image credits

The original game and map artwork are © NAMCO LTD. These are small reference thumbnails for an unofficial campaign checklist, not original artwork by this project.

## Printed source

**Namco Official Guide Book: Ace Combat 3 — Electrosphere** (ナムコ公式ガイドブック エースコンバット3 エレクトロスフィア), published by Namco Ltd., **27 May 1999**, publication code **SLPB-00010**. Planning and editing: Namco Ltd.; editorial cooperation: Q-BIST. Publication details were verified against the book's colophon on page 176.

The thumbnails use the book's **Map Guidance** panels on pages **43–147**. They are guidebook maps, not images downloaded from Ace Combat Wiki. Each thumbnail selects a representative map panel or area; it is an identification icon rather than a complete tactical reference. Missions 51 and 52 share page 147: 51 uses the narrow tunnel diagram, while 52 uses the Geofront map.

## Asset index and processing

[`crops.json`](crops.json) lists all 52 mission IDs, output filenames, printed page numbers, source scan filenames, and crop rectangles in original-image pixels (`left, top, right, bottom`). Files `01.webp` through `52.webp` correspond directly to the guide's mission IDs.

The selected panels were cropped, resized with Lanczos resampling, padded to 240 × 240 pixels without stretching, and encoded as WebP at quality 84. The source artwork and target markings were not redrawn. Whole guidebook pages and the archive are not included in this repository.
